# USDA 1911: historical Whitney triangle, eight classes

## Sources and identity

Numerical geometry and labels: `USDA1911` in **soiltexture 1.5.3**, by Julien
Moeys and contributors. The source attributes the historical triangle to
M. Whitney (1911) and credits a 2014 contribution from Nic Jelinski,
University of Minnesota. The [source is pinned to revision
db3bfb683b420989422690f3e18188b923740e40](https://github.com/cran/soiltexture/blob/db3bfb683b420989422690f3e18188b923740e40/R/soiltexture.R#L1371).
Only factual vertices and class membership are transcribed; no package
functions are bundled or executed. The source package identifies its license
as AGPL (>=3).

The [package author's gallery](https://www.julienmoeys.info/2015/02/06/texture-triangle-gallery/)
shows the historical diagram. The original Whitney publication has not been
independently retrieved for this implementation. Numerical authority here is
the pinned transcription, not an independently verified original edition.

Selector: **USDA · Whitney 1911 (8 classes)**.
Stable export ID: `USDA 1911 (Whitney, USDA1911 1.5.3, 8 classes)`.
The year identifies the historical scheme; 1.5.3 identifies the transcription.
The existing `USDA` option and its exported identifier remain unchanged.

## Historical particle-size convention

Use fine-earth percentages (<2 mm) with **sand 0.05–2 mm**, **silt
0.005–0.05 mm**, and **clay <0.005 mm**, following the pinned source and
package documentation. The 0.005 mm clay/silt cutoff is different from the
0.002 mm boundary in the modern USDA view. Modern measurements cannot simply
be relabelled as historical fractions. Switching the selector does not
convert particle-size distributions.

This is a historical mineral-texture view only, not a current USDA
recommendation or a full soil taxonomy.

## Classes and a source-label caveat

| Code | Name in the pinned source |
| --- | --- |
| C | Clay |
| SaC | Sandy Clay |
| CL | Clay Loam |
| SaCL | Sandy Clay Loam |
| L | Loam |
| SiL | Silt Loam |
| SaL | Sandy Loam |
| Sa | Sand |

**SaCL is a source-label issue requiring historical review.** The package
calls this region `Sandy Clay Loam`, although its vertices lie on the
silt-rich side (50–80% silt). This implementation preserves the pinned
code, label and polygon rather than silently correcting one without the
original publication. The selected source description in the app includes
this caveat. No claim is made that the package label has been historically
verified. Any later correction should document its primary evidence and
consider a new export ID to keep results traceable.

Plot codes link to full names in **About & methodology → Class label key**.
Results and exports preserve both. The source's right-triangle coordinates
are shown in the app's standard equilateral layout, preserving compositions
and memberships.

## Geometry and boundaries

`R/classifications/usda_1911.R` stores the 13 common vertices once in
(silt %, clay %) pairs and derives sand by difference. It has no runtime
dependency on the modern USDA definition or soiltexture.

Shared edges retain the common candidate policy. At 35% sand, 35% silt and
30% clay, the result is `boundary`, candidates C and CL, without a single
class. Pure sand, clay and silt classify uniquely as Sa, C and SiL.

## Implementation checks

- `tests/fixtures/usda_1911.csv`: one interior per source class, with the
  silt-side SaCL case explicitly labelled as a source region.
- `tests/usda_1911.R`: these cases, complete key, historical fraction metadata,
  boundary and nearby values, corners, example CSV, Shiny results and exports.
- Shared tests automatically cover area, 5,151-point coverage, gaps/overlaps,
  polygon-order independence and rendering.

These are implementation and regression checks. Historical source review,
independent package comparisons and broader scientific validation remain
future work; soiltexture is not a project dependency.
